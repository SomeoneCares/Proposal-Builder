## Verto Wave Roles

| Role | Responsibilities |
| :--- | :--- |
| **Project manager** | Manages the project throughout its lifecycle; maintains the project plan with the technical lead; reports status to stakeholders; maintains the RAID log; secures final sign-off against the agreed scope. <!-- if services --> |
| **Technical lead** | Leads the build team; runs requirements sessions with stakeholders; produces and agrees the design documents; provides technical consultation; assesses change requests; ensures testing meets the acceptance standards. <!-- if services --> |
| **Build and implementation team** | Supports requirements analysis and design documentation; executes the technical activities; contributes to project documentation and sign-off. <!-- if services --> |
| **Project Management and Governance Office** | Provides governance, oversight and standard practices so that every stage delivers value. |
| **Operations team (L1, L2, L3)** | Operates the in-scope systems under the OLA: incident handling and escalation, approved changes, advanced resolution and vendor communication. <!-- if managed_services --> |
| **Technical account manager** | Manages the technical relationship with {{customer_short}}. <!-- if managed_services --> |

## {{customer_short}} Roles

| Role | Responsibilities |
| :--- | :--- |
| **Project manager / project owner** | Primary point of accountability; coordinates stakeholders, approves deliverables, manages customer-side RAID inputs and supports timely decisions. <!-- if services --> |
| **Steering committee** | Provides strategic direction, approves major scope decisions, resolves escalations and commits resources. |
| **Technical teams** | Provide environment information, access and subject-matter support; take part in requirements and design; perform customer-side tasks in the RACI. |
| **Service owners** | Raise requests and incidents, attend service reviews and approve changes. <!-- if managed_services --> |

## Communication and Reporting

- Project status reporting and RAID log updates throughout the project. <!-- if services -->
- Monthly OLA performance reports and quarterly service reviews. <!-- if managed_services -->
- Change requests submitted in writing under the Change Management Procedure.
