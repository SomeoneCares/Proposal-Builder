## Solution Overview

The DeviceX On-Demand Services encompass an ever-growing catalog of essential branch services, for a more efficient value delivery and cost optimization. Get all your network needs without adding layers of complexity and additional license cost.

## Services in Scope

- **DNS** — Domain Name System services for branch resolution
- **DHCP** — Dynamic Host Configuration Protocol for IP address management
- **LDAP** — Lightweight Directory Access Protocol for directory services
- **RADIUS** — Remote Authentication Dial-In User Service for network access control
