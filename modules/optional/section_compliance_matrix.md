## Response Codes

Each requirement is answered with a response code that states how it is met:

| Code | Meaning |
| :--- | :--- |
| C-DX | Compliant — delivered natively by DeviceX <!-- if devicex --> |
| C-SX | Compliant — delivered natively by StackX <!-- if stackx --> |
| CC | Compliant on completion of the agreed build configuration <!-- if services --> |
| IS | Compliant through an integrated solution that Verto Wave selects, deploys and operates |
| AS | Compliant through Verto Wave's independent assurance and supervision of a control implemented by another party |
| PC | Partially compliant — the response explains the gap and how it is addressed |
| NC | Not compliant — the response explains why |
